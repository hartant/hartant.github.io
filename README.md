# Mohammed Benamar — Portfolio

Personal portfolio built with React + Vite.

- Edit all content (projects, websites, skills, links) in `src/data.js`.
- Website logos go in `public/logos/`.

```bash
npm install
npm run dev     # local preview at http://localhost:5173
npm run build   # production build in dist/
```

Every push to `main` is deployed automatically to GitHub Pages.
